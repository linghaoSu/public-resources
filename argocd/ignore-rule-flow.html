主线 — 从差异到规则,零跳转

  1. 1打开应用 → Diff Tab
    5 张 CRD 卡片 OutOfSync,Compact / Full 两种视图
  2. 2hover 差异行,点 Ignore…
    绿色新增行上的行内入口
  3. 3抽屉滑出(同屏)
    Scope 与 /spec/preserveUnknownFields 已按该行预填
  4. 4编辑并实时预览
    影响条 Eliminates N of M open diffs,命中行即时黄标 will ignore;指针无效当场报红
  5. 5Save rule
    命中行转灰 ignored · 卡片徽标 1 ignored · 绿条 Rule saved
  6. 6Ignored Fields 管理
    规则列表 / 表单 / Preview Against Manifests / 点行 Add to Rule

循环与旁路

校验循环 ↺✗ Path does not exist in manifest — 指针错误即时标红,改对才能保存(第 4 步内闭环)
调整循环 ↺命中数不符预期 → 调整 Scope,Name 留空 = 通配全部同类资源,影响条即时刷新
复用入口 ⤴灰行 hover View rule → 抽屉编辑已存规则;绿条 Manage 与抽屉 Advanced › 跳到管理页
安全退出Esc / Cancel 随时关闭抽屉,不写入任何更改
